The app runs this shortcut when you finish, so your other apps stop sending you here until tomorrow.
Set up app blocking (one time, about 5 minutes)
  1. Open Shortcuts → Shortcuts tab → +. Name it Bible Done.
  2. Add Date (Current Date), then Format Date → Date Format: Custom → yyyy-MM-dd.
  3. Add Save File. Turn off “Ask Where to Save,” set the path to bible-done.txt (in the Shortcuts folder), and turn on “Overwrite If File Exists.”
  4. Go to the Automation tab → + → App. Choose the apps to hold back (Instagram, Facebook, Mail, News…). Don’t pick Safari, because this app runs in Safari. Choose “Is Opened” and “Run Immediately.”
  5. In that automation add Get File from Folder: folder Shortcuts, path bible-done.txt, “Error If Not Found” off.
  6. Add Get Text from Input (the file), then Date + Format Date yyyy-MM-dd again.
  7. Add If: Text is not Formatted Date → inside it add Open URLs with this page’s address.

Until you finish the day’s reading, opening any of those apps sends you here. Tapping “Unlock my apps” at the end saves today’s date, and the automation lets you through until tomorrow.
